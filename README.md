> 深入本质，一通百通。 · Zero Wong

## 怎样选择

- 团队能力与合作：刘邦、唐太宗。
- 制度与执行体系：秦始皇、宋太祖、朱元璋。
- 资源动员与复杂组织：汉武帝、忽必烈。
- 信息渠道与责任机制：武则天、康熙、雍正。

## 怎样安装与调用

进入人物仓库，下载以仓库名命名的 ZIP 完整包，解压后将同名文件夹放入 Codex 的 skills 目录。新开会话后提出“用唐太宗视角分析这个团队问题”。根目录 SKILL.md 用于预览，完整研究笔记保存在 ZIP 内。

分析时给出目标、事实、限制与备选方案；要求区分史料事实、框架归纳与现代迁移。可以让两位人物分别分析同一个问题，再比较结论。

## 依据与边界

以传世史料与历史研究为依据，保留反例、战争成本、权力压制、制度副作用与失败案例。短标题和现代提问是分析概括，不是人物原话，也不代表赞同其全部行为。具体来源与审校记录见各完整包。

整理方法参考[女娲 · Skill造人术](https://github.com/alchaincyf/nuwa-skill)。
